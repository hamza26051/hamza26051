## How I work

- **Make the technical story visible.** A model is only useful when people can understand what it is doing and where it may fall short.
- **Keep the data in the conversation.** Distribution, privacy, bias, and evaluation belong in the project—not as an afterthought.
- **Build the whole path.** I like owning the journey from experiment and API to interface and documentation.
